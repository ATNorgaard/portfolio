# Wordmark

The identity mark: tight mono initials followed by a lime slash.

```jsx
<Wordmark initials="AN" />
```

SiteHeader and SiteFooter each render one already, so reach for this
directly only in a custom shell. The `mark` glyph is always lime — that
single coloured character is the whole logo.
