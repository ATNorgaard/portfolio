# SiteFooter

Three-column ink footer: the mark, one line of mono text, a back-to-top link.

```jsx
<SiteFooter>Andreas Nørgaard · AI Solutions Architect</SiteFooter>
```

Deliberately plain. The ContactBlock above it does the closing work, so the
footer only has to end the page — resist adding link columns or a newsletter
form to it.

The centre line is hidden below 800px.
