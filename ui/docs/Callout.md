# Callout

A deeper panel with a thick olive rule down its left edge, holding one short
statement set larger than body copy.

```jsx
<Callout label="Mit arbejdsprincip">
  Forretningen først. Teknologien med. Ingen hype.
</Callout>
```

Use once per page at most. This is the place a principle gets stated
outright, and it only carries weight because nothing else on the page is
formatted like it.

Keep the statement to one line — it is a pull quote, not a paragraph.
`tone="on-ink"` adapts it to a dark section.
